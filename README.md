# Generative AI Experiments

## Overview
This repository contains practical experiments demonstrating Generative AI using Python and pretrained AI models.

## Experiments
- **Audio Generation:** Convert text into speech using gTTS.
- **Code Generation:** Generate programming code using Salesforce CodeGen.
- **Fill-Mask Prediction:** Predict missing words using Hugging Face Transformers.

## Technologies Used
- Python
- Google Colab
- gTTS
- IPython
- Hugging Face Transformers
- Salesforce CodeGen

## How to Run
1. Open the notebook in Google Colab.
2. Install the required packages.
3. Run each code cell sequentially.
4. Enter text or prompts and observe the generated outputs.

## Purpose
To explore Generative AI applications, including audio generation, code generation, and natural-language processing.
